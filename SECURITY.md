# Security

Use **Report a vulnerability** on the repository's [Security Advisories page](https://github.com/sabereey/rookcue/security/advisories) to contact the maintainers privately. Include the source commit or CLI version, operating system and relevant behavior. Keep real knowledge data, credentials and pairing invitations out of public issues.

RookCue handles user-owned local knowledge and supports encrypted sync with storage you configure. See the [LAN guide](docs/lan-direct-sync.md) for invitation and device trust handling.
