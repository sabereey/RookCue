How to hand off a task from Grok to Codex

Save a checkpoint in Grok, open the same project in Codex, and ask it to continue the previous task with RookCue. The checkpoint tells Codex what has been done, which files to read, and where to pick up.

Start with RookCue connected to both agents on the same macOS or Linux computer. Open the same project folder in both sessions. This walkthrough uses a sample task with 30 items.

Save the checkpoint in Grok

Ask Grok to record the task with RookCue. After reviewing the first ten samples, save the results in review.md in the project and ask Grok to pause.

Use RookCue to save a checkpoint. I’ve reviewed samples 1–10. The results are in review.md. Next, continue at sample 11. Pause here and keep this task open.

Resume the same task in Codex

Use RookCue to continue the previous task. Read the latest checkpoint and tell me where you’ll pick up.

Check that Codex reports the original task ID, can read review.md, and plans to start at sample 11. After reviewing samples 11–20, ask Codex to update the file and save a new checkpoint on the same task.

Verify the return to Grok

In a fresh Grok session in the same folder, ask RookCue to continue the task again. The task should still be open under its original ID, with 20 of 30 samples reviewed and sample 21 next. If both agents try to save from the same checkpoint, beta.10 can reject the stale save and let the agent reload the latest progress.

The sample uses synthetic records. Both checkpoint saves and readbacks were replayed with RookCue beta.10. See the handoff contract and beta.10 release notes for details.

RookCue stores task records locally. Saved lessons require your approval.
