面向 AI AGENT 的本地记忆

换一个 Agent，

在一个 Agent 里保存进度，换一个也能接着做。RookCue 让 Codex、Grok 和 Claude Code 在你的电脑上共用任务记录和经验库。

开始使用 下载 beta.10

支持 macOS 和 Linux

试一次跨 Agent 接续。

在同一台电脑上为支持的 Agent 安装一次，再让两个 Agent 打开同一个项目。

  1. 对 Agent 说「帮我从 GitHub 安装 RookCue」。
  2. 在 Grok 中说「用 RookCue 记录这次任务」，然后保存一个检查点。
  3. 用 Codex 打开同一个项目，说「继续上次任务」。

工作记录保留在本机。经验经你批准后才进入共享经验库。
