Try your first handoff.

Install once for supported agents on the same computer, then open the same project in both.

  1. Ask your agent to install RookCue from GitHub.
  2. In Grok, say “Use RookCue to record this task” and save a checkpoint.
  3. Open the same project in Codex and say “Continue the previous task.”

RookCue stores task records locally. Saved lessons require your approval.
