# RookCue 0.1.0-beta.10

## English

This prerelease protects shared task checkpoints when two agents are working
from the same saved progress. The updated skill asks the runtime to save only if
its base checkpoint is still current. If an agent has already saved newer progress,
the second agent reloads and reconciles the two updates. A guarded save also
rejects writes to tasks that have since been closed.

- `rookcue-0.1.0-beta.10-plugin.tar.gz` contains the shared skill, Codex plugin and local marketplace manifest.
- `rookcue-0.1.0-beta.10-source.tar.gz` contains the buildable source and documentation.
- `gmem-0.1.0-beta.10-darwin-arm64.tar.gz` and `gmem-0.1.0-beta.10-linux-x64.tar.gz` are the native packages.
- `SHA256SUMS` and `install-verification.json` provide download checksums and the installation and upgrade test results.

For a shared installation, run the installer from the new skill with the same
runtime directory, then start fresh sessions. Update app-managed Codex plugins
through Codex. Existing tasks, approved knowledge and old checkpoints need no
migration. Older standalone clients can still write checkpoints independently;
use the updated skill and matching runtime on both sides to guard their saves.
macOS native binaries are ad hoc signed. See the package instructions for installation.

## 简体中文

本次预发布保护两个 Agent 从同一份检查点继续工作时的进度。新版技能要求运行时在
保存前核对所读取的检查点。若另一方已保存新进度，后保存的一方需要重读并合并。
任务已结项时，带检查条件的保存也会被拒绝。

- `rookcue-0.1.0-beta.10-plugin.tar.gz` 包含共享技能、Codex 插件和本地插件源清单。
- `rookcue-0.1.0-beta.10-source.tar.gz` 包含可构建源码和文档。
- `gmem-0.1.0-beta.10-darwin-arm64.tar.gz` 和 `gmem-0.1.0-beta.10-linux-x64.tar.gz` 是原生安装包。
- `SHA256SUMS` 和 `install-verification.json` 提供下载校验值与安装升级验证结果。

共享安装请从新版技能运行安装器，沿用原运行时目录并开启新会话。由应用管理的
Codex 插件请在 Codex 中更新。原有任务、已批准经验和旧检查点无需迁移。旧独立客户端
仍可直接保存检查点，两端都应使用新版技能和对应运行时来启用保存保护。
macOS 原生包使用临时签名，安装方式见包内说明。
